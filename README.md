# Honeybee Bakery — Website Redesign Case Study

A website redesign case study for **Honeybee Bakery**, a fictional neighborhood bakery: an original ("before") site, a modern redesign ("after"), and a case-study page explaining the thinking behind every change.

**Live site:** https://brittanynation.github.io/redesign-case-study/

## What it demonstrates

- **Design process** — auditing an existing site task-by-task, reordering content by visitor priority (sitemap / wireframe thinking), setting a visual direction, then building the result.
- **Rationale writing** — every key change on the case-study page is tied to a specific user or business reason, not just a visual preference.
- **Redesign execution** — the same content (hero, menu highlights, about, testimonials, visit information) carried from a dated, cramped layout into a warm, mobile-first design with a honey, cream, and warm-brown palette.
- **Front-end basics** — semantic HTML, accessible fundamentals (skip link, labelled navigation, focus states, contrast-safe color choices), mobile-first responsive CSS, CSS-only visuals with no external images, and a small vanilla-JS navigation toggle.
